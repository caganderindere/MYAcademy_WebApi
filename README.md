## 🚀 About The Project

**Serie A Football Platform**, Serie A futbol organizasyonunu modern bir web arayüzü üzerinden yönetmek ve görüntülemek amacıyla geliştirilmiştir.

Proje; maç fikstürlerini, maç detaylarını, takım bilgilerini, gol/kart/oyuncu değişikliklerini ve dinamik puan durumunu tek bir platformda sunar.

🎯 Amaç sadece CRUD işlemleri yapmak değil; **API geliştirme, API tüketimi, ilişkisel veri modelleme ve maç sonuçlarından anlamlı istatistikler üretmek** üzerine kurulmuştur.
